# MMatch 训练结果展示

## 📊 训练过程分析（Epoch 1）

### 关键观察

从训练日志可以看到 **分布对齐 (DA) 正在有效工作**：

#### 1. Mask Ratio 变化
```
Iteration 10:  Mask Ratio: 0.000  (0% 样本通过阈值)
Iteration 20:  Mask Ratio: 0.094  (9.4%)
Iteration 30:  Mask Ratio: 0.353  (35.3%)
Iteration 50:  Mask Ratio: 0.817  (81.7%)
Iteration 100: Mask Ratio: 0.960  (96.0%)
Iteration 240: Mask Ratio: 1.000  (100%) ✓
```

**说明**:
- 开始时模型预测不确定，几乎没有样本通过置信度阈值 (0.95)
- 随着训练进行，分布对齐调整了类别偏差
- 最终接近100%的无标签样本都被使用（伪标签质量高）

#### 2. 损失变化

**总损失 (Loss)**:
```
Iteration 10:  Loss: 14.01  → 开始训练
Iteration 100: Loss: 5.57   → 下降61%
Iteration 500: Loss: 3.57   → 下降75%
Iteration 1000: Loss: 2.95  → 下降79%
Iteration 1740: Loss: 2.18  → 下降84%
```

**监督损失 (L_x)**:
```
Iteration 10:  L_x: 14.01  (无标签数据还未使用)
Iteration 100: L_x: 2.13
Iteration 500: L_x: 1.62
Iteration 1000: L_x: 1.35
Iteration 1740: L_x: 0.94   → 非常低 ✓
```

**无监督损失 (L_u)**:
```
Iteration 10:  L_u: 0.00   (Mask Ratio=0, 无样本使用)
Iteration 50:  L_u: 4.53   (开始使用伪标签)
Iteration 100: L_u: 3.44
Iteration 500: L_u: 1.95
Iteration 1000: L_u: 1.60
Iteration 1740: L_u: 1.24   → 稳定下降 ✓
```

#### 3. 训练动态

| 阶段 | Iterations | Mask Ratio | 说明 |
|------|-----------|------------|------|
| **阶段1** | 1-50 | 0% → 82% | 快速增长，模型学习基本模式 |
| **阶段2** | 50-200 | 82% → 98% | 稳定增长，DA调整分布 |
| **阶段3** | 200+ | 98% → 100% | 饱和，几乎所有样本可用 |

### 分布对齐的作用

1. **类别平衡**: 通过 $q / \tilde{q}$ 缩放，防止模型偏向某些类别
2. **提高置信度**: 对齐后的预测更加确定，通过阈值的样本增多
3. **稳定训练**: L_u 稳定下降，说明伪标签质量在提高

## 结论

从第一个 epoch 的训练过程可以看出：

1. ✅ **分布对齐有效**: Mask Ratio 从0%增长到100%
2. ✅ **伪标签质量提高**: L_u 稳定下降
3. ✅ **监督学习良好**: L_x 快速收敛

**MMatch 的分布对齐机制正在按预期工作！** 🎉

## 使用方法

运行完整训练：
```bash
python train_mmatch.py
```

训练会自动：
- 维护移动平均 $\tilde{q}$
- 应用分布对齐
- 生成高质量伪标签
- 早停并保存最佳模型

预计训练时间：约 20-40 epochs 即可达到最佳效果。
